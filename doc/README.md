# doc · 自用模式文档

两种自用模式各自一个文件夹，互不混放。

| 文件夹 | 模式 | 状态 |
| --- | --- | --- |
| `workbuddy/` | WorkBuddy 免费额度解冻探测（24 小时窗口，解冻后首次调用） | 已实现 |
| `gemini/` | Gemini / Antigravity 定时开窗（5 小时 + 7 天窗口，重置后首次调用） | 设计 |

每个文件夹内的固定四件套：

- `产品需求文档.md` — 需求、范围、验收标准
- `技术设计文档.md` — 实现方案、数据结构、接口
- `任务拆解清单.md` — 分阶段任务与出口条件
- `免费额度解冻探测设计.md` — 解冻探测专项设计（workbuddy 独有，gemini 对应 `定时开窗设计.md`）

上游文档在 `docs/`（`docs/subsystems/` 是子系统设计参考），与本目录互不干扰。
